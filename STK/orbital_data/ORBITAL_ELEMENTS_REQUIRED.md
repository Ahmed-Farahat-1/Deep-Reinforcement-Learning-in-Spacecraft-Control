# Illustrative Baseline Orbital Elements for STK Visualization

### Keplerian Orbital Elements (LEO Baseline)
- **Central Body:** Earth (WGS-84)
- **Orbit Type:** Low Earth Orbit (LEO), Circular
- **Semi-Major Axis ($a$):** $6878.14\text{ km}$ (Altitude $h = 500.0\text{ km}$)
- **Eccentricity ($e$):** $0.0001$ (Nominally Circular)
- **Inclination ($i$):** $45.0^\circ$
- **Argument of Perigee ($\omega$):** $0.0^\circ$
- **Right Ascension of Ascending Node (RAAN / $\Omega$):** $0.0^\circ$
- **True Anomaly ($
u$):** $0.0^\circ$
- **Orbital Period:** $\approx 94.6\text{ minutes}$ ($5677\text{ seconds}$)

### Note on Academic Transparency
These orbital parameters are illustrative baseline assumptions for 3D animation purposes. The attitude dynamics were evaluated over a $100\text{ s}$ window (representing $\approx 1.76\%$ of one orbit).
